# v0.6.4 — Version banner and Docker documentation

This patch corrects two descriptions from v0.6.3. It does not change authentication, routing, connection lifetimes, or configuration.

- The version banner says "Named secrets with per-user tracking." Each configured name has one base secret, not several independent secrets.
- The Docker Hub examples use v0.6.4. The description also explains how the `ee`, `dd`, and WEB links relate to the base key.
- A regression test covers the version banner and build metadata.

The Docker Hub workflow publishes the description when its source changes on `main`. It does not run for release tags alone.

Existing configurations remain valid. The bounded WEB I/O and Middle-End diagnostics from v0.6.3 remain unchanged.
