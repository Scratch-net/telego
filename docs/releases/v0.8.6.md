# TeleGO v0.8.6

## Go security update

TeleGO now builds with Go 1.27.4, released on November 10, 2026.
Both Go modules and the pinned Docker build images use this version.

Go 1.27.4 includes security fixes for `net/http`, cgo, the Go command, the compiler, and the linker.
It also includes fixes for the runtime, networking, and cryptography packages.
See the [official Go release history](https://go.dev/doc/devel/release#go1.27.4) for details.

## Release dependencies

Updated GoReleaser to 2.20.1.
The gateway and manual WEB examples now pin Certbot 5.10.0 and its image digest.

All declared Go and Python dependencies remain at their latest compatible versions after the release audit.
The audit also covered CI actions, Node.js, Playwright, Chromium, NGINX, and the certificate image.
Unused upstream module-graph entries retain their existing versions.

## Validation

The default race, `gc_opt` race, production-tag, and 32-bit production-tag suites passed with Go 1.27.4.
Both Go modules pass `go fix` and `go vet` with default and production tags.
Lint reports no issues.
The Docker build, NGINX integration, RPM, Python dependency, transfer-tool, and Chromium checks passed.
GoReleaser 2.20.1 accepted the release configuration, and both Compose examples passed syntax checks.

The production vulnerability scan found no affected imported packages or reachable vulnerable symbols.
It reported one advisory in a required module without an affected import.

## Upgrade

Update the TeleGO binary or container image to v0.8.6.
Restart TeleGO to use the updated Go runtime and standard library.

This release requires no configuration changes.
