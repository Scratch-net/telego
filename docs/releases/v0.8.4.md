# TeleGO v0.8.4

## FakeTLS replay protection

Replay detection now identifies each authenticated ClientHello by its verified HMAC prefix.
Distinct connections can use an empty or repeated TLS session ID without a false replay rejection.
Exact replays and timestamp-only variants remain rejected.
Replay cache limits, expiry, and authentication checks remain unchanged.

## Linux TCP listener recovery

TCP listeners now recover from eight documented Linux network errors that affect a pending connection.
Both listener polling modes continue to accept subsequent connections.
Shutdown still completes during repeated network errors.
Resource exhaustion and permanent listener errors retain their existing shutdown behavior.
The successful accept path retains its direct system call.

## Dependency and toolchain refresh

Updated all declared dependencies in both Go modules to their latest compatible stable versions.
STUN now uses v4.0.1, including its stricter handling of attributes after MESSAGE-INTEGRITY.
Regression tests cover valid response ordering and rejection of an address outside the integrity-protected prefix.
Go 1.27.3 remains the latest stable compiler.

Updated the Python transfer tools, Playwright, CI actions, release tools, and container image pins.
Bridge tests now use Node.js 26.13.0 LTS.
The Python environment retains pyee 14.0.0 because the latest Playwright requires a version below 15.
Unused modules referenced only by upstream dependency graphs do not receive additional overrides.
Inactive workflow files in the vendored upstream snapshot remain outside the active CI configuration.

Reviewed `go fix` updates modernize Go code in both modules.

## Validation

Default and `gc_opt` race suites, production-tag tests, and 32-bit production-tag tests passed.
Linux accept fault injection covers both polling modes, resource errors, active connections, and shutdown.
Supplemental buffer, queue, pool alignment, and connection-matrix tests passed, including 32-bit execution.
Both Go modules pass `go fix -diff` and `go vet` with default and production tags.
Lint, Nginx integration, and all three Linux release builds passed.
The vulnerability scan found no affected imported packages or reachable vulnerable symbols.
The Python dependency check, 12 transfer-tool tests, and Chromium launch checks passed.

Paired local benchmarks found no significant slowdown in TCP accept/echo, replay-cache operations, or WEB validation.
Allocation counts remained unchanged.
The updated WebSocket library reduced 16 KiB masking time from approximately 710 ns to 95 ns on the measured amd64 host.
These measurements do not establish performance equivalence under all workloads.

## Upgrade

Restart Telego after the binary or container update.
This release requires no additional configuration.
Existing secrets, proxy links, and carrier values remain compatible.
