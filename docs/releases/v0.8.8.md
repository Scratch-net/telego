## WEB carrier

The `https` carrier now streams downloads by default.
The bridge keeps one download response open, and Telego sends each new frame in it at once.
Before, each batch waited for a new long poll.
If a stream breaks, the bridge asks for the same batch with an ordinary poll, and Telego sends the batch again.
After an error, that bridge page uses ordinary polls.
Set `stream-download = false` to turn streaming off.

The `websocket` carrier now uses a fair downlink queue by default.
WINDOW control frames go first, and DATA and CLOSE frames rotate across Telegram streams.
Each WebSocket message is at most 160 KiB, so a small reply does not wait behind a large download.
Set `websocket-fair-queue = false` to send frames in arrival order.

Two new options are off by default:

- `carrier-batch-kib` limits each carrier response and downlink frame. With the Nginx `keepalive_requests` and `keepalive_time` settings, it forces new connections for networks that freeze one connection after about 15-20 KB. The README describes the costs.
- `pad-first-frames` pads the first 8 batches in each direction of a session.

The managed installer and the manual example now select the `https` carrier.
Some filtered networks break WebSocket connections.
Existing installations keep their saved carrier.

## FakeTLS

`[[tls-fronting.domains]]` gives selected secrets their own cover domain.
Each domain has its own ServerHello template, certificate profile, and splice target.
An unrecognized client whose SNI names a configured domain goes to the splice target of that domain.

The record size jitter of the fake certificate now covers 16000 plus or minus 480 bytes.
Before, it used one random byte and covered 15520 to 15775 bytes only.

Optional ServerHello pacing sends each paced write with `MSG_EOR`.
Without it, Linux can merge paced segments into one full segment when it retransmits them.
`server-hello-pace-scope = "first-record"` paces only the first TLS record, at most 2048 bytes, and sends the rest in one write.
A 4 KiB response then needs 5 segments instead of 45 at a segment size of 92 bytes.
Pacing stays off by default.

Telego keeps the last good mask ServerHello profile on disk.
After a restart, it uses that profile until the first fetch succeeds.
The default directory is `$STATE_DIRECTORY` or `/var/lib/telego`.
If Telego cannot write there, it logs one line and runs without the cache.
Set `profile-cache-dir = "off"` to turn the cache off.

## Secrets

Telego now applies secret changes from a configuration reload without a restart.
Sessions of a removed or changed secret close with the new `secret_revoked` close reason.
A renamed secret counts as removed and added.
`[general] disabled-secrets` turns off listed secrets without removing them.
An added secret works for WEB after a restart.

## Diagnostics

`telego doctor` fails before its TLS check when the splice target or the certificate source is Telego itself.
Such a target loops unrecognized clients back into Telego.
Telego logs the same condition as an error at startup and starts anyway.

The DC check now sends an unauthenticated `req_pq_multi` request and requires a `resPQ` answer that echoes its nonce.
Before, any reply, close, or reset counted as success, so a middlebox that reset connections looked like a fast DC.
`telego doctor` runs this check for every DC and warns for each DC without a passing address.

The new `telego_tls_client_fingerprints{kind, ja4}` metric shows the 16 most frequent JA4 ClientHello fingerprints of authenticated clients and of mask fallbacks, plus the sum of the others.

The metrics listener accepts plain TCP only. Go enables MPTCP on listeners by default.

The README describes how to select a mask host and how a CDN in front of WEB changes client addresses.

## Upgrade

Restart Telego after the binary or container update.

These defaults change when the configuration does not set them:

- The `https` carrier streams downloads.
- The `websocket` carrier uses the fair queue with 160 KiB messages.
- Telego writes the profile cache to `$STATE_DIRECTORY` or `/var/lib/telego`. In Docker, the cache stays in the container layer unless you mount a volume there. The systemd units now set `StateDirectory=telego`.
- A configuration reload applies secret changes. Do not rename a secret in a live configuration unless you intend to close its sessions.

`telego doctor` now exits with an error for a fallback loop. Check scripts that run it.
